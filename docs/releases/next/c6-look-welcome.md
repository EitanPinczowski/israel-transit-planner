- **Language and theme:** Settings → Appearance picks the app's language (System / עברית / English) and theme (System / Light / Dark), applied at once. Stop names and searches follow the app's language.
- **Welcome tour:** the first launch shows a short tour of each mode, saved places and reminders. Skip it any time, or see it again from Settings.
- **Leg colours:** two buses in one trip now get two colours, the same on the map, its stops and the list.

- **שפה וערכת נושא:** בהגדרות ← מראה בוחרים את שפת האפליקציה (ברירת המחדל של הטלפון / עברית / English) ואת ערכת הנושא (ברירת המחדל / בהיר / כהה), והשינוי חל מיד. שמות התחנות והחיפוש הולכים לפי שפת האפליקציה.
- **סיור היכרות:** בפתיחה הראשונה מוצג סיור קצר בכל מצב, במקומות שמורים ובתזכורות. אפשר לדלג בכל שלב, ולראות אותו שוב מההגדרות.
- **צבעים לכל קטע:** שני אוטובוסים באותה נסיעה מקבלים עכשיו שני צבעים, זהים במפה, בתחנות וברשימה.
