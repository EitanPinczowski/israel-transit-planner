- **Search keeps what you typed.** Turning the phone, or Android closing the app in the background, no longer closes the search: the text and the answers are still there, with no new request.
- **Better answers in Israel.** Places abroad are never offered; "TLV", "JLM" and "Chaifa" find their towns; a train station by name ("Rehovot railway station", "תחנת רכבת תל אביב סבידור") is found from the app's own station list; and a station search lists the stops before other places with the same name (the Tel Aviv central bus station, not a shelter inside it).
- **Addresses the map server doesn't know.** When it finds only the town for a street and number, the phone's own address search (then OSM) is asked, and the town is still shown.
