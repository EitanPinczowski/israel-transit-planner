- **Home:** set any saved place as Home in Settings (🏠). A place called "Home" or "בית" is offered once.
- **Night refresh:** each night, on Wi-Fi and while charging, the app plans tomorrow's usual trips. With no signal in the morning the Trip tab still shows them ("Offline — planned last night at 02:14"), only the options still ahead.

- **בית:** אפשר להגדיר כל מקום שמור כבית בהגדרות (🏠). מקום בשם "Home" או "בית" מוצע פעם אחת.
- **רענון לילי:** בכל לילה, ב־Wi-Fi ובזמן טעינה, האפליקציה מתכננת את הנסיעות הקבועות של מחר. בבוקר בלי קליטה הן עדיין מופיעות בלשונית הנסיעה ("אין חיבור — תוכנן אמש ב־02:14"), רק האפשרויות שעוד לא יצאו.
