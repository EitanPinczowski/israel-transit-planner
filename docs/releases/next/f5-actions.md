- **Other apps can no longer trigger the app's reminder, ride and tile actions.** Only the app's own notifications, Quick Settings tile and shortcuts can start them.

- **אפליקציות אחרות כבר לא יכולות להפעיל את פעולות התזכורת, הנסיעה והאריח של האפליקציה.** רק ההתראות, אריח ההגדרות המהירות וקיצורי הדרך של האפליקציה עצמה יכולים להפעיל אותן.
