- **A train station you name still shows when the search service doesn't answer.** "Rehovot railway station" comes from the station list on the phone, but a failed or timed-out search used to throw it away with everything else. Now it stays, with "No connection" and a Retry button under it.
- **Settings → Crash log keeps the last search that found nothing.** One line: the words you searched and what each source answered (no location). It goes with the crash log only when you share it, so the next "found nothing" can be traced.

- **תחנת רכבת שמחפשים בשמה מופיעה גם כששירות החיפוש לא עונה.** "תחנת רכבת רחובות" מגיעה מרשימת התחנות שבטלפון, אבל חיפוש שנכשל או לקח יותר מדי זמן זרק אותה יחד עם כל השאר. עכשיו היא נשארת, ומתחתיה "אין חיבור" וכפתור "ניסיון חוזר".
- **הגדרות ← יומן קריסות שומר את החיפוש האחרון שלא מצא דבר.** שורה אחת: מה שחיפשתם ומה ענה כל מקור (בלי מיקום). היא נשלחת עם יומן הקריסות רק כשאתם משתפים אותו, כך שאפשר יהיה לבדוק את ה"לא נמצא" הבא.
